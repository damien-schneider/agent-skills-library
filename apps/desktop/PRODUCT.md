# Product

## Register

product

## Users

Developers and AI-agent practitioners managing skills, agents, rules, and instruction files scattered across their local machine. They need to find, inspect, edit, deduplicate, and synchronize these files without leaving a focused desktop workflow.

## Product Purpose

Another Dev Tool makes local agent configuration visible and manageable in one place. Success means users can confidently understand a file, make deliberate edits, review exactly what changed, and save without accidental disk writes or formatting surprises.

## Brand Personality

Precise, calm, trustworthy. The interface should feel familiar to users of high-quality developer tools while staying approachable enough that document editing never feels like operating an IDE.

## Anti-references

Avoid cramped document layouts, raw markdown masquerading as rendered content, ambiguous save state, hidden automatic persistence, decorative editor chrome, and dense IDE conventions that compete with the document.

## Design Principles

- Make document structure immediately legible.
- Keep editing direct and saving deliberate.
- Show state through clear controls, not explanatory clutter.
- Preserve source content predictably across editing modes.
- Let familiar interaction patterns disappear into the workflow.

## Accessibility & Inclusion

Target WCAG 2.2 AA. All editor actions must be keyboard reachable, focus must remain visible, state cannot rely on color alone, controls need accessible names, and motion must respect reduced-motion preferences.
